# Indicator Picker Redesign — "Indicators, metrics and strategies"

## Context

The picker (`apps/web/src/dialogs/IndicatorsDialog.tsx`, styled in `dialogs.css` + `indicators.css`) works but feels bare: 79 built-ins render as an undifferentiated wall of names with no descriptions, a star outline clutters every row, there's no "recently used" access, no sense of what's already on the chart, no match highlighting, no keyboard hints, and search results lose category context. This redesign applies standard picker UX patterns (TradingView/VS Code style) using the app's existing design system (tokens.css, `Modal`, `dlg-*` primitives, lucide icons) — no new dependencies.

## UX design principles

- **Speed unchanged**: click / Enter adds instantly, dialog stays open for multi-add (existing behavior preserved).
- **Info on demand**: hovering or arrow-keying a row previews it in a new right detail pane (description, category, overlay vs separate pane, scale range) — no extra clicks needed.
- **Less noise**: stars are revealed on row hover; always visible once starred.
- **Context everywhere**: "Recent" section pinned atop the All list; search results grouped under category headers; sidebar shows counts; rows already on the chart get a green-dot count badge.

## Changes

### 1. `packages/indicators` — descriptions
- `src/types.ts`: add `description?: string` to `IndicatorDefinition` (next to `keywords`).
- All 79 builtin files in `src/builtins/*.ts` and `src/builtins/financials/*.ts`: add one accurate `description` one-liner (≤ ~140 chars; e.g. RSI: "Momentum oscillator (0–100) measuring the speed and magnitude of price changes to flag overbought/oversold conditions.").
- User scripts: `UserScriptManifest` extends the definition shape, so script manifests can carry `description` automatically — verify `parseManifest`/length validators accept it (cap ~200 chars per `MAX_STRING`); extend the field allowlist only if it rejects.

### 2. `apps/web/src/indicators/store.ts` + `actions.ts` — recents
- `IndicatorPrefsData` += `recents: string[]`; new `pushRecent(type)` action (dedupe, front-insert, cap 8, renamed ids resolved like favorites via `resolveIndicatorId`).
- Bump persist version 2 → 3 with a migration adding `recents: []` (reuse `migrateRenamedPrefs`).
- `addIndicator` (`actions.ts:42`) calls `pushRecent(type)` on success. Recents stay local (no `settingsSync` change).

### 3. `IndicatorsDialog.tsx` — main rewrite
- **Layout**: Modal width 760 → 940, 3-pane `dlg-picker-body`: sidebar (200px, unchanged structure) + list + new detail pane (240px).
- **Preserved for compatibility**: `matchesQuery` export, sourceOf ("Add indicator on") mode, `.ind-row` / `.ind-star` classes, `Search indicators` aria-label, `.dlg-side-item`, aria listbox/option roles, keyboard (↑↓ wrap, Enter adds) and Modal Escape handling. Several Playwright specs depend on these.
- **List sections**: rows computed per view; cross-category views (search, starred, and the All list's pinned "Recent" section) render grouped under sticky category headers (`MOMENTUM · 4`) in registry-category order. Single-category tabs stay flat. `rows` flattens across headers for keyboard nav (`data-index` on rows only).
- **Rows**: hover-reveal star (CSS only), `<mark>` highlight of matched words in names, on-chart badge (dot + count, computed from `useIndicatorStore.instances` grouped by `type`; tooltip "N on chart"), brief "added" flash via `justAdded` state + keyframes. Custom scripts keep pencil edit; broken scripts keep their rows.
- **Detail pane**: follows `rows[idx]` — name, shortName chip (mono font), category chip, placement badge (`overlay` ? "Overlay on price" : "Separate pane"), scaleRange badge ("0–100" when set), fundamentals note for `usesFundamentals`, description paragraph (fallback: muted "No description"), Edit script button for user scripts; pane footer: star toggle + "Add to chart" primary button (`io-btn-primary`). Hidden via media query below ~880px viewport and on mobile sheets.
- **Search input**: clear (X) button when non-empty; no-results empty state gains a "Clear search" button; starred empty state hints at hover-starring.
- **Footer**: `.dlg-hints` kbd row via Modal's `footer` prop — `↑↓ navigate · Enter add to chart · Esc close` (same pattern as SymbolSearchDialog).

### 4. CSS — `dialogs.css` + `indicators.css`
- 3-pane grid in `.dlg-picker-body`; new classes: `.ind-detail*`, `.ind-sec-head` (sticky), `.ind-count`, `.ind-onchart`, add-flash keyframes, hover-reveal star rules; reuse `mark` accent styling, `.dlg-section-title`, `.dlg-hints`, `--radius-control`/`--accent-soft` tokens. Follow existing responsive breakpoints used by `.dlg-picker-body` (~1041-line media block).

### 5. Tests
- `indicators.test.ts`: recents (pushRecent dedupe/cap, `addIndicator` records recent, v3 migration).
- New `dialogs/indicatorsDialog.test.tsx` modeled on existing `symbolSearch.test.tsx`: category render, search grouping/filter, Enter adds, star toggle, on-chart badge, detail pane follows active row.

Out of scope: i18n keys (dialog is hardcoded English today, catalog is en-only), recents server sync.
