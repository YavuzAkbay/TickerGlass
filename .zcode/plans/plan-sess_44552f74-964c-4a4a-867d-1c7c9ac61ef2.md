# Full-Screen Watchlists Page

## Context

Watchlists currently live only in the left Navigator panel (`sidebar/panels/Watchlist.tsx` → `sidebar/watchlist/`), capped at a ~260–480px column. The user wants a dedicated, full-screen **Watchlists page** for detailed viewing — the sidebar panel stays as-is. This is deliberately *not* a screener (that comes later as its own screen), so the page focuses on managing/inspecting the user's own lists: richer table, list switching, live overview stats, an inline detail pane, and bulk editing.

The app has no router — navigation is zustand state, and there is no full-screen view precedent yet (`src/screener/` is an empty placeholder). We introduce a small generic **screen** concept so the future screener can reuse it.

**Decisions confirmed with user:** full takeover with its own header · click = select + preview (Enter/double-click opens chart) · multi-select + bulk actions included · company names via throttled+cached search API.

## Design

```
┌──────────────────────────────────────────────────────────────────┐
│ ←   Watchlists      [My Stocks] [Crypto] [●Flagged]   +  ⋯      │  wlp-header (48px)
├──────────────────────────────────────────────────────────────────┤
│ 24 symbols · 15 up · 9 down · avg +0.8% · top NVDA +4.2%        │  wlp-overview strip
├───────────────────────────────────────────────────────┬──────────┤
│ [Filter…]  Columns▾  Sort: Chg%▾  Rows▾  [⧉][▤]      │ DETAIL   │
├───────────────────────────────────────────────────────┤ AAPL     │
│ AAPL  Apple Inc.       232.50  +1.2%   4.2M  ▁▂▃▅▆   │ 232.50   │
│ MSFT  Microsoft Corp.  418.10  −0.4%   2.1M  ▅▄▃▃▂   │ +1.2%    │
│ …virtualized rows…                                    │ range bar│
│                                                       │ [Open →] │
└───────────────────────────────────────────────────────┴──────────┘
```

- **Header**: back button (←, "Back to charts"), title + active list name, horizontally scrollable **list tabs** (all lists + virtual flag lists; name + symbol count; right-click → list menu; `+` appends new list), right actions: Add symbol (opens `SymbolSearchDialog` in add mode), Columns menu, Density toggle, Detail-pane toggle, Overflow menu (Import .txt, Export .txt, Export CSV, Rename/Duplicate/Delete list).
- **Overview strip**: pure-function stats over the active (filtered) list: count, up/down/flat, equal-weighted avg chg%, top gainer/loser. Colored with `--up`/`--down`.
- **Table** (CSS grid, `role="grid"`, sticky header): columns = flag strip (row border) + symbol + `name` + last/chg/chg%/volume + `dayRange` (low–high bar with last-price marker) + ext + bigger trend sparkline. Header click cycles sort asc→desc→none; sorting within sections via existing `buildRows`; sections render as full-width collapsible rows with counts. DnD reorder (single-row, disabled while sorted/filtered, like sidebar). Alt+↑/↓ move, Alt+1–7 flag, type-ahead, Delete removes.
- **Multi-select**: Ctrl/Cmd+click toggle, Shift+click range, Shift+Arrow extends; floating bulk bar ("N selected — Move to list ▾ / Add alert / Remove / ×"); Delete key removes; Escape clears.
- **Detail pane** (~340px, collapsible, persisted): big price/change, market state, pre/post rows, day-range bar, kv stats (volume, prev close, high/low), flag swatches, larger trend chart with 1M/3M/6M/1Y period switch (reusing `Sparkline` parametrized), actions: Open in chart (primary), Add alert, Copy, Move to list, Remove.
- **Click model**: click = select + detail preview; Enter/double-click = `chart.setSymbol` + close screen (back to charts).
- **Keyboard**: ↑/↓ navigate · Enter open · Delete remove · Alt+↑/↓ reorder · Alt+1–7 flag · Mod+F focus filter · Escape staged: clear filter → clear selection → close screen. Gate existing `layout.chart.restore` (Escape) on `screen === 'charts'`.
- **Empty states**: no lists → create-first-list CTA; empty list → "Add symbols" CTA; filter no-match → "Clear filter".

## Implementation

### New files — `apps/web/src/watchlist/page/` (CSS prefix `wlp-`)

| File | Purpose |
|---|---|
| `WatchlistsPage.tsx` | Screen root: composes header/tabs/strip/table/detail; Escape staging; lazy-loaded by App |
| `PageHeader.tsx` | Back, title, tabs area, action buttons + overflow menu |
| `ListTabs.tsx` | Tab strip (reuse `listActionItems`, `sortedLists`, `flagRef` colors) |
| `OverviewStrip.tsx` + `aggregate.ts` | Stats UI + pure `summarize(quotes)` (unit-testable) |
| `PageTable.tsx` | Virtualized grid table, sort/filter/selection/DnD/keyboard/context menus |
| `pageColumns.tsx` | `PAGE_COLUMNS`: reuses sidebar `COLUMNS` defs for quote columns; new `name`/`dayRange` defs; page column order list |
| `PageDetail.tsx` | Detail pane incl. period-switched trend |
| `virtual.ts` | Tiny fixed-height virtualizer hook (`useVirtualRows`) — rows are fixed-height, no dependency needed |
| `pagePrefs.ts` | Persisted `useWatchlistPagePrefs` (`tickerglass-watchlist-page`): page columns, page sort, `detailOpen`, density (`compact`/`cozy`) |
| `symbolMeta.ts` | `SymbolMeta {name, exchange, type}`; sequential ~150ms-throttled queue over `feed.searchSymbols` exact-match; Map + localStorage cache (cap ~2000); `useSymbolMeta(symbol)` hook |
| `pageCsv.ts` | CSV builder for current view using `csvField`/`csvTextField` from `chart/exportData.ts` |
| `page.css` | All page styles; tokens only, light/dark + `pointer: coarse` + `prefers-reduced-motion` blocks per convention |

### Modified files

- **`store/ui.ts`** — add `type ScreenId = 'charts' | 'watchlists'`, transient `screen` field + `openScreen(id)` / `closeScreen()`; exclude from `partializeUi`. Generic so the future screener adds an id only.
- **`App.tsx`** — render `{screen === 'watchlists' && <WatchlistsPage/>}` as a fixed full-viewport layer (lazy via the `retryableLazy` pattern from `dialogs/DialogHost.tsx`); when open, set `inert` + `visibility: hidden` on shell children (`.app-top`, Navigator, center, Inspector, rail) so charts stay mounted/warm (no data reload on return) but are untabbable/unpainted. Hosts (DialogHost/ContextMenuHost/PromptHost/ToastHost) stay above the layer.
- **`watchlist/commands.ts`** — register `view.watchlists` (shortcut **Alt+Shift+W**, free) and `view.watchlists.close`; appear in palette + ShortcutsDialog automatically.
- **`layout/commands.ts`** — `enabled: () => screen === 'charts'` gate on `layout.chart.restore` so Escape doesn't double-fire.
- **`watchlist/types.ts`** — extend `ColumnId` with `'name' | 'dayRange'`; keep `ALL_COLUMNS` unchanged (sidebar set).
- **`sidebar/watchlist/columns.ts`** — inert stub defs for the two new ids so `Record<ColumnId, ColumnDef>` stays exhaustive (sidebar menu never shows them).
- **`watchlist/model.ts`** — `buildRows(items, sort, quotes, collapsedAware?, meta?)`; `sortValue` handles `'name'` (meta lookup) and `'dayRange'` (null, unsortable).
- **`sidebar/watchlist/rowMenu.ts`** — optional `opts?: { onOpen? }` param; "Open" calls it when provided (page passes set-symbol + close screen).
- **`sidebar/watchlist/Sparkline.tsx`** — add optional `width/height/limit` props (defaults = current 44×18/30) so sidebar is unchanged; page uses bigger sizes + period limits (22/66/132/252 bars).
- **`navigator/Navigator.tsx`** — in the watchlist section header next to the Plus button: "Open watchlists screen" IconButton (Maximize2) running `view.watchlists`.
- **`dialogs/SymbolSearchDialog.tsx`** — default-mode pick also calls `closeScreen()` if a screen is open ("open" always means go-to-chart).
- **`i18n/en.ts`** — flat `wlp.*` keys (header, tabs, strip, filter, selection, detail, empty states, export). Column labels stay literal English like the existing sidebar columns.

### Reuse map (no reimplementation)

`resolveActive`/`flagRows`/`buildRows`/`sortedLists`/`isFlagRef`/`parseTxt`/`formatTxt` (`watchlist/model.ts`) · `useWatchlistStore` mutations + `useWatchlistPrefs.activeId` (shared active list with sidebar) · `useLiveQuotes(symbols, {ext})` (`quotes/hooks.ts`) · `changeClass`/`fmtAuto`/`fmtSigned`/`fmtCompact` (`sidebar/format.ts`) · `useFlash` (`sidebar/watchlist/columns.ts`) · `rowMenu` + `FLAG_ICONS` · `listActionItems` (`ListSwitcher.tsx`) · `IconButton`/`Menu`/`DropdownMenu`/`openContextMenu`/`promptName`/`confirmDialog`/`toast`/`actionToast` (`ui/`) · `useApi` (`sidebar/hooks.ts`) · `downloadBlob` (`persist/layouts.ts`) · `csvField`/`csvTextField` (`chart/exportData.ts`) · `commands.execute('chart.setSymbol'|'alert.create'|'watchlist.*')`.

### Risks / mitigations

- **Z-index layering** — page layer must sit below modal/popover portals; verify against `ui.css` values during implementation.
- **Name fetches** — sequential queue, only visible rows + selection, permanent cache; if a provider rate-limits, the column degrades to `—` gracefully.
- **1000-item lists** — virtualization keeps DOM ~visible rows; sparkline fetches only occur for rendered rows (existing 10-min cache).
