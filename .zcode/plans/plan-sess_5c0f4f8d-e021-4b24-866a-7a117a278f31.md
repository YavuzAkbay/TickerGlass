# Market Screener — full-screen page

## Context

TickerGlass has full-window "screens" (watchlists today) and the `ScreenId` type in `store/ui.ts` already anticipates a screener ("watchlists today, screener later"). This adds a **Screener screen**: a full-screen market scanner over four asset classes (stocks, ETFs, commodities, crypto) with filters, sorting, breadth summary, and live-updating rows — original UI, FinViz/TradingView-inspired only in concept. Cost-controlled by design: default view shows **10 results**, and the *universe slice* actually subscribed for quotes is a separate, modest knob (default top 100).

**Decisions taken** (no answer received on the two questions, so I go with the recommended options): bundled static universes + existing `/quotes` batching (zero new backend work, deterministic cost); v1 data = quotes + static universe metadata (no live fundamentals; the scan engine stays provider-agnostic so a server scan could plug in later).

## Architecture

**Data flow (all existing machinery):** universe slice (top-N by static rank) → `useLiveQuotes(slice)` (`quotes/hooks.ts`) → QuoteStream does batching (100/req), WS ticks, 15s polling, 60s refresh; server SmartCache/guard bounds upstream cost. Filters/sort/slice run client-side over quotes + static metadata; only the top `resultLimit` rows render (virtualized). Cost scales with universe size, not result count. No server changes.

**Universe** (`apps/web/src/screener/universe/`): compact tuple datasets expanded by a builder, each entry `{ symbol, name, sector|category|group, exchange?, approxCap? }` with an as-of stamp:
- `stocks.ts` ~400 US names ranked by market cap (sector + exchange + approx cap $B)
- `etfs.ts` ~130 by AUM (category: Broad US / Sector / International / Bonds / Commodity / Crypto / Leveraged / Dividend)
- `commodities.ts` ~45 futures+ETFs (group: Energy / Precious / Industrial Metals / Agriculture / Livestock / Broad)
- `crypto.ts` ~40 majors (group: Layer 1 / DeFi / Meme / Payments / Gaming)
- `index.ts` — `getUniverse(cls)` with per-class dynamic import; `UNIVERSE_AS_OF` stamp shown in UI. Unit test validates uniqueness/shape.

**Prefs** (`screenerPrefs.ts`, persisted `tickerglass-screener-prefs` v1, `parseScreenerPrefs` validator, `pagePrefs.ts` pattern): per-class filters, sort, `resultLimit` (default 10; options 10/25/50/100/All), `universeSize` (default 100; options 50/100/250/All; auto-expands if resultLimit exceeds it, effective value shown in strip), columns, density, detailOpen.

**Model** (`model.ts`, pure + unit-tested): `applyFilters(universe, quotes, filters)`, `sortResults` (quote keys via `COLUMNS[id].sortValue`, static keys rank/symbol/name/cap, nulls last), `sliceResults`, filter preset application (`presets.ts`: Top gainers / Top losers / Most active).

## UI (page components in `apps/web/src/screener/page/`, CSS prefix `.scr-`, tokens from `theme/tokens.css`)

```
ScreenerPage (.scr-root, position:fixed z-index:100, staged Escape)
├─ ScreenerHeader — back btn, title + universe as-of, detail-pane toggle, More menu (Export CSV, options)
├─ ClassTabs — role=tablist: Stocks / ETFs / Commodities / Crypto (data-testid="scr-tab-*")
├─ FilterBar — search input (Ctrl/Cmd+F), per-class dropdowns (sector/category/group, exchange),
│   price / chg% / volume min-max, presets menu, Options menu (universe size, result limit, density, columns)
├─ ScanStrip — breadth (up/down/flat, avg chg%, top/bottom movers via moved summarize()),
│   active-filter chips with x + Clear all, universe info ("Top 100 of ~500"), loading skeleton / quote error
└─ main: ResultsTable (virtualized via moved virtual.ts, sortable headers, aria-sort, flash-on-tick,
│   heat gutter tinted by chg% color-mix like wlp) + ScreenerDetail (right pane: big price, sparkline 296×72
│   with 1M/3M/6M/1Y, day-range bar, static meta rows, actions)
└─ ResultRow — cells reuse COLUMNS[id].render(q) + Sparkline; static columns (cap/sector/exchange) rendered
    from universe meta; row menu: Open in chart / Add to watchlist… (list picker) / Copy symbol
```

Quality details: skeleton rows on first load (reduced-motion aware), empty state with "Clear filters", missing-quote rows show em-dashes (never hidden), footer "Showing 10 of 87 matches" with "Show more" (bumps limit), `data-testid="scr-root|row-<sym>|col-*|..."` mirroring `wlp-*`, full keyboard nav (↑/↓ focus, Enter = open in chart, Escape staged), light/dark via tokens, ≤768px behavior following `page.css` conventions.

## Reuse (do not re-implement)

- `retryableLazy` + inert shell parts + ErrorBoundary wiring — `App.tsx` (copy the WatchlistsPage pattern)
- `useLiveQuotes` / quote store — `quotes/hooks.ts` (no new fetch code)
- `COLUMNS` cell renderers + `useFlash` — `sidebar/watchlist/columns.ts`; `Sparkline` (parameterized); `DayRangeBar` if extractable (else ~20-line local copy)
- **Move to shared**: `watchlist/page/virtual.ts` → `ui/virtualRows.ts`; `watchlist/page/aggregate.ts` (`summarize`) → `quotes/summary.ts`; update watchlist imports + test paths
- CSV: `csvTextField`/`csvField` (`chart/exportData.ts`) + `downloadBlob` (`persist/layouts.ts`) → new `screenerCsv.ts`
- UI primitives: `IconButton`, `Menu`/`DropdownMenu`, `Popover`, `Prompt`/`confirmDialog`, `actionToast`; form patterns from `dialogs/controls.tsx`
- Commands: `commands.register` pattern (`watchlist/commands.ts`); `layout/commands.ts` Escape guard already generic; `SymbolSearchDialog` screen-close already generic
