# Add a dismiss button to the chart symbol card

## Context

The glass quote card at the top-left of each chart (`AAPL · Apple Inc. · price · volume · OHLC`) is rendered by `SymbolCard` and currently can't be dismissed — it permanently covers chart area. The user wants a small ✕ button on/near the card to close it at will. Agreed UX: clicking ✕ collapses the card to a small ticker pill in the same spot; clicking the pill brings the full card back; the closed state persists per chart (like the other legend settings).

## Changes

### 1. `apps/web/src/store/chartView.ts` — persisted flag
- Add `quoteCard: boolean` to `StatusLineSettings` (line 13) and `quoteCard: true` to `DEFAULT_STATUS_LINE` (line 25).
- No other store changes needed: the existing `parseStatusLine` loop (lines 43–44) auto-admits new boolean fields, and `pickChartView` persists `statusLine` as-is. Existing tests use `toEqual({ ...DEFAULT_STATUS_LINE, ... })` spreads so they keep passing.

### 2. `apps/web/src/center/SymbolCard.tsx` — ✕ button + collapsed pill
In `Card`:
- Subscribe to `statusLine` via `useStore(session.view, s => s.statusLine)`.
- Helper `setQuoteCard(v)` writing `{ statusLine: { ...sl, quoteCard: v } }` through `session.view.getState().set(...)`.
- When `quoteCard` is **true** (today's card): render as now, plus an ✕ button (`X` from lucide-react, `size={14}`) as the last item of the `.sc-top` row — after `<SessionClock>`, before the mobile chevron `toggle`. `aria-label`/`title` = `t('symbolHeader.hide')`, onClick → `setQuoteCard(false)`.
- When **false**: portal a collapsed pill instead of the card — a small button (class `sc-closed`) showing the ticker symbol, `aria-label`/`title` = `t('symbolHeader.show')`, onClick → `setQuoteCard(true)`. Same `slot`, same portal site (`SymbolCard` component, lines 32–40).

### 3. `apps/web/src/center/symbolCard.css` — styles
- `.sc-close`: ~20×20 icon button, flex:none, transparent background, muted color, `border-radius: var(--radius-control)`, hover `background: var(--hover)`. It inherits `pointer-events: auto` from the `.sc-card button` rule (line 25) — must stay a real `<button>`.
- `.sc-closed`: pill for the collapsed state, styled like `.sc-bar-interval` / the indicator pills (translucent surface, `border-radius: 999px`, `padding: 2px 10px`, font-weight 600, muted → strong on hover). It sits directly in the legend slot (not inside `.sc-card`), so it must set `pointer-events: auto` itself since `.io-legend` is `pointer-events: none`.
- Extend the duplicate-legend rule (line 84) so the engine's own legend line also stays hidden while collapsed:
  ```css
  .io-legend-header:has(.sc-card) + .io-legend-info,
  .io-legend-header:has(.sc-closed) + .io-legend-info { display: none; }
  ```

### 4. `apps/web/src/i18n/en.ts` — labels
Add next to the existing symbol card keys (lines 44–49):
- `'symbolHeader.hide': 'Hide symbol card'`
- `'symbolHeader.show': 'Show symbol card'`

### 5. Test
In `apps/web/src/persist/persist.test.ts` near the `parseStatusLine` case (line 1767), add an assertion that `{ quoteCard: false }` is kept and absent/invalid falls back to `true`.

Also check a narrow (mobile) viewport: ✕ sits next to the chevron in the compact card.
